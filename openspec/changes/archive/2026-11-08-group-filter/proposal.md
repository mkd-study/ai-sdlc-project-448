# Proposal

## Why

Выбор группы помогает сузить список сотрудников при проверке доступа и выдаче разрешения. В форме выдачи повторный перечень групп в поле «Кому выдать» дублирует селектор группы; связанный выбор «группа → все её сотрудники или конкретный сотрудник» делает получателя разрешения понятнее.

## What Changes

- Сохранить независимый выбор группы перед полями «Сотрудник» и «Кому выдать». Проверка доступа сохраняет вариант «Все группы» и нынешнее поведение.
- В форме выдачи группа по умолчанию «Не выбрана», доступны все сотрудники, включая сотрудников без групп. При выборе группы показывать только её участников по `User.groupIds`, сохраняя порядок.
- В «Кому выдать» оставить пустой вариант и сотрудников; при выбранной группе добавить «Все сотрудники группы». Повторный перечень групп убрать. Без выбранной группы вариант «Все сотрудники группы» отсутствует.
- «Все сотрудники группы» выдаёт одно разрешение выбранной группе, действующее для текущих и будущих участников. Для пустой группы этот вариант также доступен. Выбор конкретного сотрудника по-прежнему выдаёт прямое разрешение.
- Сохранять выбранного сотрудника, пока он входит в видимый список; иначе сбрасывать выбор без автоматического выбора другого сотрудника. Сменой фильтра не менять выбранный сервис.
- При смене или снятии группы сбрасывать выбранное «Все сотрудники группы», чтобы получатель не менялся автоматически. После импорта сохранять этот выбор только при сохранении той же группы.
- Показывать понятное сообщение для группы без сотрудников и согласовывать выбор с текущей конфигурацией после импорта.
- Сохранить полный расчёт доступа со всеми источниками, выдачу и удаление разрешений, защиту от дублей, импорт, экспорт и хранение в браузере. Фильтр не меняет конфигурацию и не сохраняется между перезагрузками.

Вне области изменения: редактирование состава групп, множественный выбор групп, массовая выдача отдельных прямых разрешений, поиск по имени, отдельный режим «Без группы», фильтрация списка разрешений и изменение модели доступа.

## Capabilities

### New Capabilities

- `employee-selection`: выбор сотрудника с необязательным фильтром по группе при проверке доступа; выбор конкретного сотрудника или всех участников выбранной группы при выдаче разрешения, включая согласование выбора после изменения списка и импорта.

### Modified Capabilities

Нет. Требования `access-calculation` и `config-import` сохраняются; новая возможность относится к выбору в интерфейсе.

## Impact

- `src/components/PermissionsPanel.tsx`: состав вариантов получателя, связь с выбранной группой, сброс и проверка допустимости действия. `App.tsx` сохраняет реализованный фильтр проверки доступа.
- `src/app/employee-selection.ts`: уже реализованное общее поведение фильтрации и согласования сотрудника, доступное через `src/app/index.ts`.
- `src/components/Permissions.test.tsx`: обновлённые сценарии выдачи и импорта. Тесты проверки доступа и общей фильтрации остаются регрессионными проверками; скриншоты формы выдачи требуется обновить.
- Модель `Config`, формат JSON версии 1, ключ localStorage, зависимости и доменный расчёт остаются прежними. Сетевые операции не добавляются.
