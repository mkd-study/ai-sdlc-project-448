    # Proposal

## Why

Сейчас при проверке доступа и выдаче разрешения сотрудника нужно искать в полном списке. Фильтр по принадлежности к группе позволит сначала сузить список, затем выбрать нужного сотрудника, сохранив существующие операции симулятора.

## What Changes

- Добавить независимые фильтры по одной группе перед полями «Сотрудник» и «Кому выдать». Область обоих фильтров подтверждена пользователем.
- По умолчанию показывать «Все группы» и полный список сотрудников, включая сотрудников без групп. При выборе группы показывать только её участников по `User.groupIds`, сохраняя порядок.
- Сохранять выбранного сотрудника, пока он входит в видимый список; иначе сбрасывать выбор без автоматического выбора другого сотрудника. Сменой фильтра не менять выбранный сервис.
- В форме выдачи фильтровать только сотрудников: все группы остаются доступными получателями разрешений независимо от фильтра.
- Показывать понятное сообщение для группы без сотрудников и согласовывать выбор с текущей конфигурацией после импорта.
- Сохранить полный расчёт доступа со всеми источниками, выдачу и удаление разрешений, защиту от дублей, импорт, экспорт и хранение в браузере. Фильтр не меняет конфигурацию и не сохраняется между перезагрузками.

Вне области изменения: редактирование состава групп, множественный выбор групп, поиск по имени, отдельный режим «Без группы», фильтрация списка разрешений и изменение модели доступа.

## Capabilities

### New Capabilities

- `employee-selection`: выбор сотрудника с необязательным фильтром по группе при проверке доступа и выдаче разрешения, включая согласование выбора при изменении списка и независимость от операций с конфигурацией.

### Modified Capabilities

Нет. Требования `access-calculation` и `config-import` сохраняются; новая возможность относится к выбору в интерфейсе.

## Impact

- `src/components/App.tsx`, `src/components/PermissionsPanel.tsx`: фильтры, отображение доступных вариантов и обработка выбора.
- `src/app/`: общее поведение фильтрации и согласования выбора, доступное компонентам через `src/app/index.ts`.
- `src/components/App.test.tsx`, `src/components/Permissions.test.tsx` и тесты нового модуля слоя приложения: новые сценарии и проверки совместимости.
- Модель `Config`, формат JSON версии 1, ключ localStorage, зависимости и доменный расчёт остаются прежними. Сетевые операции не добавляются.
